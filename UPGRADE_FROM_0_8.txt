ElectionLab 0.8 -> 0.9
========================

1. CLOSE ElectionLab first.
2. Extract the ElectionLab 0.9 ZIP somewhere temporary.
3. Run Update_Existing_Install.bat from the extracted 0.9 folder.
4. Enter the path to your existing ElectionLab installation.
5. Reopen ElectionLab with the existing Run_ElectionLab.bat.
6. Confirm the lower-left build label says:
   Pre-1.0 build 0.9 · diagnostics + state operations + polling

The updater preserves:
- portable_config.json
- your selected external data root
- .venv
- Knowledge Vault / researched profiles
- portraits
- campaigns and branches
- saved election simulations
- research caches and model data

NEW BUG-REPORT LOG
------------------
ElectionLab now keeps one recurrent log for the most recent session:

<your selected data root>\Logs\latest_session.log

You can open/copy its path from Settings -> Diagnostics.
If the app hangs and then recovers, send that log after the session. It includes UI-stall timing and the active ElectionLab action.
